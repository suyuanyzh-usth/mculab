# 非职务开发声明（个人申请专用）

> **适用情形**：你以个人名义申请，且该软件**不属于**职务作品——即不是为完成本单位工作任务、也不是主要利用单位物质技术条件所开发。
>
> **为什么需要这份文件**：审查员看到申请人是高校教师、软件又明显用于教学，第一反应就是"这是不是职务作品"。没有这份说明，很容易被要求补正甚至驳回。
>
> **谁盖章**：需要你所在单位（院系或学校科研管理部门）盖章确认。如果单位不愿盖章，说明权属存在争议，建议改走"职务开发、单位申请"那一套（见同级的 02 文件夹）。

## 附件建议（提高通过率）

按审查实践，口头声明不如证据有力。建议随声明一并准备：

| 证据 | 说明 |
|---|---|
| 代码提交记录截图 | Git 提交时间集中在夜间/周末，可作为"业余时间"的旁证 |
| 个人设备信息 | 开发所用电脑为个人所有（购买凭证或设备序列号） |
| 个人账号记录 | 大模型 API、云服务等以个人账户付费订阅的记录 |
| 单位证明 | 上述盖章页，效力最强 |

## 如果单位拒绝盖章怎么办

不要勉强。这种情况通常意味着单位认为属于职务作品，此时正确做法是：

1. 由**单位**作为著作权人申请（走 `02-职务开发（单位申请）` 那一套）；
2. 或在单位内部先明确权属（如签署权属确认书），再决定申请人。

强行以个人名义申请、又拿不出非职务证明，最常见的结果是**补正通知**，来回耗时往往超过一个月。
