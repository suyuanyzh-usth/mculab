## 一分钟启动

```bash
bash tools/check_env.sh     # ① 环境自检（Node ≥22.5、SDCC 是否就绪）
node server/index.js        # ② 启动，默认 0.0.0.0:8080
```

Windows 可直接双击 **`start.bat`**，Linux/macOS 用 **`./start.sh`**。
启动横幅会打印本机与局域网地址，学生用 `http://<你的IP>:8080` 访问。

# 3) 登录
#   教师：teacher / teacher123   （登录后请立即改密码）
#   学生：由教师导入名单后，用「学号 + 初始密码」登录，或自助注册认领
```

首次启动会自动创建数据库 `data/mculab.db`、导入 15 个实验题目、生成默认教师账号。

## 任意网络都能用（已工程化，不只是"理论上可以"）

| 场景 | 状态 | 做法 |
|---|---|---|
| 校园局域网 | ✅ 开箱 | 直接启动 |
| 宿舍/家庭（NAT 后） | ✅ | 内网穿透（frp/cpolar）见[部署指南](docs/01-部署指南.md) |
| 公网 HTTP | ✅ 仿真/实验全可用 | 真机烧录需 HTTPS，页面会明确提示 |
| 公网 HTTPS | ✅ 全功能 | **内置 TLS**：`--tls-cert/--tls-key`，无需 Nginx |
| 手机 4G/5G | ✅ | 移动端布局 + 可"添加到主屏幕" |
| 弱网 | ✅ | gzip 压到 **26%**；ETag 命中 **304（0 字节）** |
| 断网 | ✅ 可续用 | Service Worker 缓存；离线仍能画图/仿真，编译与提交提示需联网 |

### 不想每天开电脑、也不想点 .bat？

三种方式见 **[任意网络部署](docs/04-任意网络部署.md)**：

```bash
# ① 云服务器（推荐，真正任意网络，一条命令）
docker compose up -d --build

# ② 直接跑在 Linux 上（apt 装 SDCC + systemd 开机自启）
sudo apt install -y sdcc && sudo systemctl enable --now mculab

# ③ 留在 Windows 本机，但做成开机自启服务（一次安装，之后不用再点任何脚本）
#    deploy/install-windows-service.ps1
```

编译能力依赖 SDCC：Windows 便携版已内置；Linux 由发行版包提供（`apt install sdcc`），
镜像构建时会真的编译一次程序做自检。

关键设计：**仿真 100% 在浏览器本地执行**，所以带宽只影响首屏与编译请求，
100 人同时仿真也不会把服务器压垮。

## 功能一览

### 基础必备（全部已实现）

| 需求 | 实现情况 |
|---|---|
| 教师随时迭代升级 | 题库以 `server/seed.js` 为准，启动时 **UPSERT** 同步，改完重启即生效 |
| 任意网络访问 | 默认 `0.0.0.0`，内网直连；公网三方案见 [部署指南](docs/01-部署指南.md) |
| 教师导入班级-学生数据 | CSV/TSV/空格分隔批量导入，自动建账号、设置初始密码、生成名单快照 |
| 监测练习次数与数据 | 编译/仿真行为全部入库，教师端看板含练习次数、通过率、完成实验数、提问数 |
| 回答学生提问 | 学生提问 → 助教自动答 → 教师可追加答复并关闭 |
| 接入大模型/智能体 | OpenAI 兼容接口，**密钥只存服务端**；未配置时自动降级为离线规则助教 |
| IDE 写 C 并编译出 .hex | SDCC 4.6.0 在线编译，支持 `<stdio.h>`/`<string.h>`/`<math.h>` 等标准库 |
| 内嵌常见库 | 自带 `intrins.h`/`reg51.h`/`reg52.h` 垫片，**兼容 Keil C51 写法**（`sbit`/`code`/`interrupt`） |
| Proteus 式原理图 | SVG 编辑器，40 脚 DIP 封装级引脚定义，正交自动布线优先零交叉，元件不可重叠 |
| 引脚严格准确 | `MCU_DIP40_PINS` 按真实物理引脚号（1–40）定义，含 P0/P2 倒序 |
| AI 分析电路错误 | 20+ 条接线规则引擎（电源/地/EA/晶振/限流电阻/共阴共阳/短路…），可点击定位 |
| 上传 .hex 驱动硬件 | 支持加载 `.hex`/`.ihx` 直接仿真 |
| 15 个仿真项目 | 流水灯、二进制计数、蜂鸣器（鸣叫/音乐）、数码管（静态/动态）、矩阵键盘、LCD1602、UART、外部中断、定时器、I²C、SPI、PWM、综合 |

## 教学使用建议

1. 教师先在「教师后台 → 批量导入学生」粘贴名单（学号,姓名,班级,初始密码）。
2. 学生用学号 + 初始密码登录（或点「学生注册」自己设密码）。
3. 学生按「实验题目 → 载入起始代码 → 编译 → 载入预设电路 → 仿真 → 仪器看波形 → 生成报告」推进。
4. 教师用「学情分析」找出练习多但通过率低的学生，针对性辅导。
