# 教学管理：实验任务与成绩册

面向教师的两块功能，入口在顶部导航：**实验任务**、**成绩册**（仅教师可见）。

---

## 一、实验任务（发布要求 + 记录过程）

### 教师怎么用

1. 顶部「实验任务」→ 右上「新建任务」；
2. 选择对应实验（15 个内置实验之一）、填写任务名称与**实验要求**；
3. 设定**开始/结束时间**，勾选「立即发布」→ 保存；
4. 列表里点「完成情况」查看每位学生的打开时间、提交时间、用时。

### 学生看到什么

打开对应实验题目时，详情上方会出现蓝色任务横幅：实验要求、时间窗口、当前状态，
以及两个按钮——**开始实验**（记录首次打开时间并跳转 IDE）、**提交本次实验**（记录结束时间）。

### 用时是怎么算的

```
用时 = 提交时间 − 首次打开时间
```

- **只有第一次打开会记录**，之后反复刷新、重新进入都不会重置（防止刷时间）；
- 超出教师设定窗口的部分**不计入**：如果学生提前打开（窗口未开始），从窗口开始时刻算；
  如果学生拖到窗口结束后才提交，最多算到窗口结束；
- 教师端按「已提交人数 / 总人数」和平均用时汇总。

> 老师若想严格限时，把窗口设成"实验课那一节的 2 小时"即可：学生课后补交的，
> 用时会被截断到窗口结束，不会出现"用时 3 天"这种数据。

## 二、成绩册（自定义构成 + 自动总评）

### 两级结构

```
总评 = Σ(环节权重 × 环节得分) ÷ Σ环节权重
环节得分 = Σ(子项权重 × 子项分) ÷ Σ子项权重
```

- **环节**：一门课里的实验/考核项，默认取全部 15 个实验，可增删、改名称、改权重；
- **子项**：每个环节内部的评分维度，默认四项——
  **功能实现 40% / 电路设计 20% / 实验报告 20% / 调试过程 20%**，同样可增删改权重。

权重不需要凑满 100，系统按**实际合计**归一化（权重 2:1 就等于 2/3 与 1/3）。

### 两个容易误解的规则

1. **未打分的子项不计入分母**。例如某环节只打了"功能实现 90"，该环节得分就是 90，
   而不是被其余未打项拉低到 36。
2. **某环节全部未打分，则该环节不参与总评**。因此开学初只评了实验一，
   学生总评显示的就是实验一的分数，不会因为其余 14 项空着而变成个位数。

### 及格线与小数位

默认 **60 分及格、保留 0 位小数**，可在成绩册左上方直接改（0–4 位）。

### 打分与导出

- 成绩册右侧先选「当前环节」，表格按学生列出各子项输入框，输入 0–100，留空表示未评分；
- 每行实时显示该环节得分、总评与「及格/不及格」；
- 「详情」可看该生所有环节的分数明细；
- 「导出 CSV」导出全量：班级、学号、姓名、每个环节×子项、总评、是否及格（Excel 可直接打开）。

## 三、高频错误统计

`GET /api/teacher/errors` 会按「实验 + 编译错误信息」聚合失败次数与涉及人数，
用于发现共性难点。目前尚未在界面上单独开面板，数据已可在接口层查看；
下一版会并入教师后台的学情分析区。
