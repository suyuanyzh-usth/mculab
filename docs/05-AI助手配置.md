# AI 助手：配置 DeepSeek / 智谱 GLM

本平台有两种方式让 AI 助教工作，**先确认你用的是哪一种**：

| 部署方式 | 是否需要配置密钥 | 说明 |
|---|---|---|
| **云端链接**（`*.app.workbuddy.host`） | ❌ 不需要 | 已接入云服务大模型，开箱即用 |
| **自建**（本机 / 学校服务器 / Docker） | ✅ 需要 | 按下文配置 DeepSeek 或 GLM |

> 云端版本在「答疑」页右上角显示 **「云端 AI 已连接（模型名）」** 即表示正常，无需任何配置。
> 只有自建版本才需要下面的步骤。

---

## 一、DeepSeek 配置（推荐）

### 1. 获取 API Key

1. 打开 <https://platform.deepseek.com>，手机号注册；
2. 左侧「API keys」→「创建 API key」；
3. 复制生成的 `sk-...`（**只显示一次**，请立即保存）；
4. 在「充值」页充值（少量即可，见下方成本估算）。

### 2. 在平台后台填写

登录教师账号 → **教师后台 → AI 大模型设置**：

| 字段 | 填写值 |
|---|---|
| 启用大模型 | ✅ 勾选 |
| 快速选择厂商 | `DeepSeek`（会自动填下面两项） |
| 接口地址 | `https://api.deepseek.com/v1` |
| 模型名称 | `deepseek-v4-flash` |
| API 密钥 | 粘贴 `sk-...` |

点 **保存设置** → 点 **测试连接**，出现绿色成功提示即可。

> ⚠️ **模型名请注意**：`deepseek-chat` / `deepseek-reasoner` 已于 **2026-07-24 停用**，
> 现在必须用 `deepseek-v4-flash`（快、便宜）或 `deepseek-v4-pro`（强、贵约 3 倍）。

### 3. 成本估算

按官方价目（每百万 token）：输入 $0.14 / 输出 $0.28（V4-Flash）。
一次实验答疑约 2k 输入 + 1k 输出 ≈ **0.0006 美元**；100 名学生各问 10 次 ≈ **0.6 美元**。

---

## 二、智谱 GLM 配置

1. 打开 <https://open.bigmodel.cn>，注册后在「API Keys」创建密钥；
2. 后台填写：

| 字段 | 填写值 |
|---|---|
| 接口地址 | `https://open.bigmodel.cn/api/paas/v4` |
| 模型名称 | `glm-4-flash`（有免费额度）／`glm-4`（更强） |

3. 保存 → 测试连接。

> 智谱全系共用同一个端点，换模型只改模型名即可。

---

## 三、本地模型（无密钥、断网可用）

适合机房不能上外网的场景：

```bash
# 在服务器上安装并拉取模型
ollama pull qwen2.5:7b
ollama serve          # 默认监听 127.0.0.1:11434
```

后台填写：接口地址 `http://127.0.0.1:11434/v1`，模型 `qwen2.5:7b`，**密钥留空**。

平台已允许 localhost 免密钥（`server/llm.js` 中对本地地址放行）。

---

## 四、验证配置是否生效

1. 教师后台点「测试连接」→ 应返回绿色提示与模型回复；
2. 切到「答疑」视图，新建提问，若回答不是「（离线助教模式…）」开头的模板文字，
   说明大模型已生效；
3. 若仍走离线模板，说明密钥/地址/模型名有误，看后台返回的错误信息。

### 常见错误

| 现象 | 原因 |
|---|---|
| `401 Unauthorized` | 密钥错、复制时带了空格/换行 |
| `404 model not found` | 模型名写错（如仍用 `deepseek-chat`） |
| `402 Insufficient Balance` | 账户余额不足 |
| 连接超时 | 服务器无法访问外网，或被防火墙拦截；改用本地 Ollama |
| 一直返回离线模板 | 「启用大模型」未勾选，或保存后未刷新页面 |

## 五、AI 能力边界（如实说明）

当前 AI 助教的上下文来自三处，**都由平台自动装配**：

1. 题目原文与起始代码；
2. 学生当前代码；
3. 原理图的自动接线诊断结果（缺上拉、晶振无电容、导线交叉等）。

**尚未实现**的两项能力，请不要误以为已有：

- **知识库检索（RAG）**：教师上传讲义/PDF 后由向量检索召回——未实现。目前模型只能看到上面三项。
- **联网搜索**：让模型自行检索网络资料——未实现，且自建大模型通常也不具备联网能力。

需要"按教师讲义回答"时，当前可行做法是把关键知识点写进**实验要求**（教师后台发布），
它会随题目一起进入 AI 上下文。

## 六、教师知识库（让 AI 按你的讲义回答）

入口：**教师后台 → AI 知识库**。

- **上传文件**：支持 `.txt / .md / .markdown / .csv / .json / .html / .log`
- **粘贴录入**：Word、PDF 请直接复制内容粘贴（浏览器读不了这两种二进制格式，硬解析会乱码）
- 单份 ≤ 2MB、≥ 20 字；可多选批量上传，列表里可删除

### 检索是怎么做的（必须知道）

实现是**关键词相关度检索**：中文按二元组切词、英文按单词，再用 IDF 给"晶振""串口"
这类低频词更高权重，最后取相关度最高的 3 段注入到 AI 的提问里。

- ✅ 优点：不依赖任何 embedding 服务，离线可用、零额外成本
- ⚠️ 局限：**不是语义检索**。学生问"提拉电阻"而讲义写"上拉电阻"，可能召不回来

如果日后要升级为向量检索，只需替换 `server/index.js` 里 `kbSearch()` 的打分部分，接口不变。

## 七、联网搜索

入口：**教师后台 → 联网搜索**。当前内置 **Tavily**（<https://tavily.com>，按次计费，有免费额度）。

1. 注册 Tavily，创建 API Key（形如 `tvly-...`）；
2. 后台填入密钥、勾选「允许 AI 联网搜索」、保存；
3. 之后 AI 回答前会先搜索，把结果作为【联网搜索结果】附在提问里。

**未配置密钥时不会假装能搜**：接口会明确返回「教师尚未启用联网搜索 / 缺少密钥」，
界面上也有对应提示。

## 八、两条调用路径的分工

| 部署方式 | AI 由谁回答 | 知识库/搜索是否生效 |
|---|---|---|
| 云端链接 | 云服务内置大模型（无需密钥） | ✅ 生效（检索在服务端） |
| 自建 + DeepSeek/GLM | 你在后台配的模型 | ✅ 生效 |

两种路径都会先做知识库检索与（可选）联网搜索，再交给模型。
